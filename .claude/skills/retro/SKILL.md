# Retro

Append to `docs/process/retros.md`:

- Feature, dates, number of review rounds per task.
- What slowed us down, and the root cause.
- What to change: in an agent prompt, a skill, a gate, or a template.
- **Generic lessons** (apply to any game): draft the change against the `gamedev` template repo and list the PR or the patch.
