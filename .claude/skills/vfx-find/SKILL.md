# VFX find

1. Search `docs/vfx/catalog.md` by tag. If something close exists, plan a variant instead of a new effect.
2. Gather 3-5 references (clips or GIFs from games in the same style; link, do not copy) into `docs/design/refs/<slug>/vfx.md`, with notes on timing, colour, shape and what makes each one read well at small size.
3. Write a one-paragraph effect brief: trigger, duration, intensity, palette, how often it fires, cost budget.
