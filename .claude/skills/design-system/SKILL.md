# Design a system

Add a section to `docs/design/gdd.md`:

```markdown
## <System>
Purpose: what player need or fantasy it serves.
Rules: numbered, precise.
States and transitions: list or diagram.
Tunables: name, meaning, owner, data file.
Interactions: with each existing system.
Failure and edge cases: what happens at zero, at max, offline, on interruption.
Feedback: what the player sees and hears (VFX, UI, audio hooks).
Out of scope for now.
```
